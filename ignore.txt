# Things disksync never copies. Compiled into the binary: edit, then rebuild.
# Only photos (jpg png tiff heic webp gif bmp camera RAW), .mp4 .mp3 .txt .pdf are ever copied
# (KEEP in main.rs), and only if their contents pass the checks in safety.rs; this list is on top of that.
# Matching is case-insensitive, on file AND folder names:
#   name     -> exact name, anywhere          (AppData)
#   *x       -> name ends with x              (*.exe)
#   x*       -> name starts with x
#   *x*      -> name contains x               (*crack*)
#   /path    -> that path under the source drive root, `*` = any one folder (/Users/*/AppData)

# --- Executables / scripts: never copied (not in KEEP). They are listed in
#     _executables.xlsx / _executables.pdf on the backup; the extensions are EXEC in src/report.rs.

# --- Installers, cracks, keygens, mods, trainers: skip the whole folder (and its readme/nfo .txt) ---
# ponytail: substring match, so "crackers.jpg" is skipped too; tighten to exact names if that bites.
*crack*
*keygen*
*trainer*
*installer*
mods
# Archives / disk images (may contain the above) - never copied, not unpacked
*.zip
*.rar
*.7z
*.iso

# --- Office files with macros ---
*.docm
*.xlsm
*.pptm

# --- Browser profiles, exported passwords, AppData ---
AppData
User Data
*password*
*.kdbx

# --- Windows system / re-creatable stuff ---
$Recycle.Bin
System Volume Information
/Windows
/Program Files
/Program Files (x86)
/ProgramData
/Recovery
/$WinREAgent
/PerfLogs
